# GAIP 2026 with ESS — Insurance Command Center

A live, interactive demo of an ML-driven dynamic insurance pricing dashboard for LFP ESS fleets. Companion artifact to the RiskDS 2026 paper *"ML-based LFP ESS Dynamic Fire & Performance Warranty Insurance"* (Customer Experience & Inclusion track).

## What it shows

Five demo states the audience can move through (or watch unattended via the auto-play tutorial):

1. **Splash** — animated "ESS Insurance using Machine Learning" hero with delayed color highlights on `ESS` (celestial light) and `Machine Learning` (neon violet)
2. **Tutorial prompt** — "Would you like a guided tour?"
3. **Tutorial mode** — a finger-pointer overlay walks through the dashboard step-by-step, auto-advancing every 6 seconds. Designed for unattended booth presentation
4. **Login** — demo credentials `ID = GAIP`, `Password = 2026` (printed below each field)
5. **Dashboard** — two view modes:
   - **Aggregated**: 4 KPI cards (portfolio premium, average per-system, fleet risk, average SOH), 365-day premium timeline, 5-precursor risk radar (D3), top-3 risk drivers, behavioural counterfactual slider
   - **Individual**: 5 ESS systems as color-coded cards (NORMAL = celestial light, WARNING = amber, CRITICAL = red with pulse glow). Click any card to drill into per-system 365-day premium history, top drivers, and recommendations

## Stack

Single self-contained `index.html` with CDN dependencies — zero build step.

- [Pretendard](https://github.com/orioncactus/pretendard) — Korean-capable display + body sans
- [IBM Plex Mono](https://www.ibm.com/plex/) — numerics
- [Chart.js 4](https://www.chartjs.org/) — premium timelines
- [D3 v7](https://d3js.org/) — 5-precursor radar
- [PapaParse 5](https://www.papaparse.com/) — CSV ingestion

## Data

`data/ess_dashboard_data.csv` — 5 ESS × 365 days = 1,825 rows of proxy operational telemetry (SOH, SOC, temperature, cell voltage variance, 5 precursor scores, weekly premium with 95% CI, regime status, top drivers).

Generated by `scripts/generate_dashboard_data.py`. Each system has a distinct narrative character so the demo shows side-by-side colour states:

| System | Character |
|---|---|
| ESS-01 | Steady Performer (NORMAL all year) |
| ESS-02 | Aging Fast (climbs to WARNING) |
| ESS-03 | SOC Volatility (intermittent WARNING) |
| ESS-04 | Summer Thermal Stress (WARNING in Jul–Aug) |
| ESS-05 | Cell Imbalance Drift (ends as WARNING / CRITICAL) |

The premium values use a demo amplifier (×80 of the raw Tower A model output) so risk-driven movement is visually meaningful at booth distance — the per-row `p_fire_7d`, `p_fire_low`, `p_fire_high` columns hold the unamplified Tower A posterior probabilities for transparency.
